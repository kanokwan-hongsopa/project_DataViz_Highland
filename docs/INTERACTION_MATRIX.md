# Interaction & Cross-Filtering Matrix (`INTERACTION_MATRIX.md`)

เอกสารนี้ระบุรายการการโต้ตอบ (Interactions) และการเชื่อมโยงข้อมูลข้ามองค์ประกอบ (Bidirectional Cross-filtering) ทั้งหมดในระบบ `project_DataViz_Highland`

---

## 1. ตัวกรองส่วนกลาง (Global Filter Bar Controls)

| องค์ประกอบ UI (`index.html`) | Event ที่รับ | State ที่เปลี่ยนแปลง (`js/state.js`) | ผลลัพธ์การอัปเดต (Components Updated) |
|---|---|---|---|
| **ปุ่มเลือกโหมดปี** (`[data-year="2022" | "2023" | "compare"]`) | `click` | `yearMode` | อัปเดต KPI ทั้งหมด, โหมดแผนที่ (Single Year vs Swipe 2022\|2023), ซีรีส์กราฟทุกแท็บ และ Filter Chips |
| **ปุ่มเลือกช่วงเดือน** (`#btn-month-picker-toggle` & `.month-cell`) | `click` | `months` (อาร์เรย์เดือน `1`–`12`) | อัปเดตค่าเฉลี่ยภูมิอากาศ, ผลรวมจุดความร้อน, กราฟรายเดือน, แผนที่คลัสเตอร์ และป้ายช่วงเดือน |
| **ปุ่มลัดช่วงเดือน** (`#btn-month-fair`: ม.ค.–ก.ย. / `#btn-month-all`: 12 เดือน) | `click` | `months: [1..9]` หรือ `[1..12]` | สลับโหมดเปรียบเทียบยุติธรรม (ม.ค.–ก.ย. ที่ HRDI มีครบสองปี) กับทั้งปี 12 เดือนทันที |
| **Dropdown จังหวัด** (`#filter-province`) | `change` | `province` (+ ตรวจสอบความสอดคล้องของ `district`, `tambon`, `stationId`) | กรองข้อมูลทุกชุดตามจังหวัด, ซูมแผนที่ไปยังจังหวัด, เปิดแผงข้อมูลจังหวัด (Docked Panel) และกรองรายการอำเภอ/ตำบล/สถานีใน Dropdown |
| **Dropdown อำเภอ** (`#filter-district`) | `change` | `district` (+ ตรวจสอบ `tambon`, `stationId`) | กรองข้อมูลสถานีภูมิอากาศและจุดความร้อนตามอำเภอ พร้อมแสดงป้ายแจ้งเตือนว่าข้อมูลฝน HII เป็นระดับจังหวัด |
| **Dropdown ตำบล** (`#filter-tambon`) | `change` | `tambon` (+ ตรวจสอบ `stationId`) | กรองข้อมูลสถานีและจุดความร้อนตามตำบลที่เลือก |
| **Dropdown สถานีตรวจวัด** (`#filter-station`) | `change` | `stationId`, `province`, `district` | เลือกสถานีพร้อมตั้งค่าจังหวัดและอำเภอของสถานีนั้นโดยไม่ถูกล้างค่า (Fixed Cascading Update) |
| **Dropdown แหล่งข้อมูลสถานี** (`#filter-weather-source`) | `change` | `weatherSource` (`all`, `OpenWeatherMap`, `HRDI Weather Station`) | กรองสถานีภูมิอากาศและระเบียนรายเดือนตาม `source_type` พร้อมอัปเดตป้ายจำนวนสถานี (`50` / `47` / `3` แห่ง) และกรองตัวเลือกใน Dropdown สถานี |
| **Dropdown ตัวแปรภูมิอากาศ** (`#filter-climate-metric`) | `change` | `climateMetric`, `overviewMapMetric` | เปลี่ยนตัวแปรที่แสดงบนกราฟแนวโน้ม, กราฟจัดอันดับจังหวัด, Box Plot, แผนที่ Choropleth และแท็บ Q2 |
| **Dropdown ความสูงจุดความร้อน** (`#filter-hotspot-elevation`) | `change` | `hotspotElevation` (`all`, `high`, `low`) | กรองจุดความร้อนแบบ `AND` ร่วมกับทุกตัวกรองใน KPI, แผนที่ และกราฟจุดความร้อนทั้งหมด |
| **Dropdown การใช้ประโยชน์ที่ดิน** (`#filter-hotspot-landuse`) | `change` | `hotspotLanduse` | กรองจุดความร้อนแบบ `AND` ตามหมวดการใช้ที่ดินจริง |
| **Dropdown พื้นที่โครงการ HRDI** (`#filter-hotspot-project`) | `change` | `hotspotProject` (`all`, `in_project`, `outside`) | กรองจุดความร้อนแบบ `AND` ตามการอยู่ในเขตโครงการพัฒนาพื้นที่สูง |
| **ปุ่มภาพรวม 9 จังหวัด** (`#btn-quick-study-overview`) | `click` | ล้างเฉพาะ `province`, `district`, `tambon`, `stationId` | คืนมุมมองแผนที่กลับสู่ภาพรวม 9 จังหวัดศึกษาโดยคงตัวกรองปี/เดือน/ตัวแปรไว้ |
| **ปุ่มรีเซ็ตทั้งหมด** (`#btn-reset-filters`) | `click` | `resetState()` | คืนค่าทุกตัวกรองกลับสู่ค่าเริ่มต้นและซูมแผนที่กลับสู่ภาพรวมพื้นที่ศึกษา |
| **ป้าย Filter Chips** (`#active-filter-chips .chip-remove`) | `click` | ล้างเฉพาะตัวกรองของ Chip ที่คลิก | ลบตัวกรองเฉพาะจุดและอัปเดตทุกองค์ประกอบทันที |
