# Highland Climate & Hotspot Interactive Dashboard (2022–2023)

> **Highland Climate & Hotspot Intelligence**  
> การวิเคราะห์แนวโน้มสภาพภูมิอากาศและความสัมพันธ์กับจุดความร้อนบนพื้นที่สูง 9 จังหวัดของประเทศไทย ปี 2022–2023

เว็บแดชบอร์ดระดับพรีเมียมสำหรับการวิเคราะห์แนวโน้มสภาพภูมิอากาศและความสัมพันธ์กับจุดความร้อนบนพื้นที่สูง พัฒนาขึ้นด้วยสถาปัตยกรรม Vanilla HTML5, CSS3 และ Modern JavaScript ES Modules โดยอิงข้อมูลจริงเชิงประวัติศาสตร์ปี 2022–2023 เพื่อตอบคำถามวิจัยและวิเคราะห์หลัก 9 ข้อ (Q1–Q9) ตามข้อกำหนด [BRD.md](BRD.md) และ [HANDOFF.md](HANDOFF.md)

## ภาพรวมการออกแบบและการปรับปรุงระบบ (Platform Redesign Highlights)

แดชบอร์ดได้รับการออกแบบใหม่ทั้งหมดตามแนวคิด **Climate Intelligence Platform**:

1. **สุนทรียภาพระดับมืออาชีพ (Atmospheric Visual Design):**
   - พื้นหลังภาพทิวเขา หมอกฝน และประกายไฟป่าในระยะไกล (`assets/hero_landscape.jpg`) พร้อมเลเยอร์ Dark Gradient Overlay เพื่อให้อ่านตัวหนังสือภาษาไทยได้ชัดเจน
   - โครงสร้างการแสดงผลแบบ Bento Grid พร้อมเอฟเฟกต์ Frosted Glassmorphism (Backdrop Blur, ขอบการ์ดบางโปร่งแสง)
   - โทนสีธรรมชาติ: Deep Forest Green, Dark Navy (`#060d17`), Teal (`#0d9488`), Cyan (`#22d3ee`) และสีส้มอำพัน (`#f97316`) สำหรับจุดความร้อน
   - ปราศจาก Emoji โดยสิ้นเชิง โดยใช้ไอคอน SVG เชิงเทคนิคและตัวอักษร Prompt/Sarabun ที่ทันสมัย

2. **แผนที่ประเทศไทย 77 จังหวัดแบบโต้ตอบ (77-Province Interactive Thailand Map):**
   - แสดงขอบเขตจริงของประเทศไทยครบทั้ง 77 จังหวัดจาก GeoJSON (`data/thailand_provinces.geojson`)
   - **68 จังหวัดนอกพื้นที่ศึกษา:** แสดงด้วยสีเทาอมน้ำเงินเข้ม (Muted Blue-Grey) ไม่สามารถคลิกเลือกได้ และไม่แสดงสีที่สร้างความเข้าใจผิด
   - **9 จังหวัดในพื้นที่ศึกษา:** แสดงด้วยสีฟ้า-เขียวอมฟ้า (Teal/Cyan) รองรับ Choropleth, เอฟเฟกต์ Hover, และคลิกเพื่อเจาะลึก
   - **หน้าต่างรายละเอียดจังหวัด (Docked Detail Panel):** เมื่อคลิกเลือกจังหวัด จะเปิดหน้าต่างสรุปข้อมูลสถานี สภาพอากาศ ฝน และจุดความร้อนข้างแผนที่ พร้อมปุ่ม **"ภาพรวม 9 จังหวัด"** เพื่อกลับสู่มุมมองรวม

3. **แถบเลื่อนเปรียบเทียบแผนที่ 2022 vs 2023 (Draggable Map Swipe Divider):**
   - ในโหมด "เปรียบเทียบ 2022–2023" ผู้ใช้สามารถคลิกและลากเส้นแบ่งแนวดิ่ง (`<|>`) ซ้าย-ขวา เพื่อดูความแตกต่างของชั้นข้อมูลสภาพอากาศหรือจุดความร้อนระหว่างปี 2022 (ฝั่งซ้าย) และ 2023 (ฝั่งขวา) บนพิกัดและมาตราส่วนเดียวกัน

4. **รัศมี 10 กิโลเมตรรอบสถานีตรวจวัด HRDI (Geodesic 10 km Buffer Circle):**
   - เมื่อเลือกสถานีตรวจวัด ระบบจะวาดวงกลมรัศมี 10 กิโลเมตรจริงบนผิวโลก (`L.circle` ด้วยรัศมี 10,000 เมตร) พร้อมคำนวณและแสดงจำนวนจุดความร้อนดาวเทียมที่ตรวจพบภายในรัศมีดังกล่าว
   - ถอดตัวเลือกวิธีการคำนวณระยะทางออกจาก UI โดยบังคับใช้มาตรฐานรัศมี 10 กิโลเมตรอย่างเคร่งครัดตามข้อกำหนด

5. **ระบบตัวกรองแบบรับรู้บริบทข้อมูล (Dataset-Aware Cascading Filters):**
   - รายการอำเภอและตำบลใน Dropdown จะปรับเปลี่ยนอัตโนมัติตามบริบทของแท็บที่กำลังเปิดอยู่ (เฉพาะอำเภอที่มีสถานีสภาพอากาศในแท็บ Climate หรือทุกอำเภอที่มีจุดความร้อนในแท็บ Hotspot) ป้องกันปัญหาตัวกรองไม่ตรงกับข้อมูล

6. **กราฟิกการวิเคราะห์ทางสถิติขั้นสูง:**
   - เส้นแนวโน้มค่าเฉลี่ยแบบโค้งมน (Monotone Spline) พร้อมจุดข้อมูลและ Tooltips ที่ละเอียด
   - กราฟแท่งจัดอันดับจังหวัดและสถานีแบบไล่เฉดสี พร้อมตัวเลขกำกับทุกแท่ง
   - กราฟ Heatmap 50 สถานี × 12 เดือน โดยแสดงเดือนที่ไม่มีข้อมูลตรวจวัดด้วยสัญลักษณ์ `—` ไม่แทนค่าเป็น 0
   - แผนภูมิการกระจายตัวของข้อมูลสภาพอากาศและจุดความร้อน (Monthly Distribution)
   - กราฟกระจาย (Scatter Plots) ความสัมพันธ์สภาพอากาศกับจุดความร้อน พร้อมเส้นแนวโน้มการถดถอยเชิงเส้น (Historical Linear Regression Trendline) และค่าสัมประสิทธิ์สหสัมพันธ์เพียร์สัน (*r*)

## ขอบเขตการศึกษาและชุดข้อมูลจริง (Real Data Only)

- **ช่วงเวลาศึกษา:** ปี ค.ศ. 2022 และ 2023 (ย้อนหลังเชิงประวัติศาสตร์ ไม่มีการคาดการณ์ล่วงหน้า)
- **9 จังหวัดพื้นที่ศึกษา:** เชียงใหม่, เชียงราย, น่าน, ตาก, กำแพงเพชร, พิษณุโลก, เพชรบูรณ์, กาญจนบุรี, แม่ฮ่องสอน
- **สถานีตรวจวัดสภาพอากาศ HRDI:** 50 สถานี (977 station-month records)
- **ข้อมูลน้ำฝนระดับจังหวัด HII:** 9 จังหวัด × 24 เดือน (216 records)
- **จุดความร้อนจากดาวเทียม VIIRS:** 106,036 รายการ (แบ่งพาร์ทิชัน 24 เดือน)
- **ขอบเขตภูมิศาสตร์ประเทศไทย:** 77 จังหวัดจาก GeoJSON ความละเอียดสูง

## โครงสร้างหน้าเว็บและคำถามวิจัย 5 แท็บ (Q1–Q9)

| หน้า (Tab) | คำถามที่ครอบคลุม | ฟังก์ชันเด่น |
|---|---|---|
| **1. ภาพรวมพื้นที่ศึกษา** | **Q1, Q5, Q9** | แผนที่ประเทศไทย 77 จังหวัด, แถบเลื่อนเปรียบเทียบ 2022/2023, การ์ดตัวชี้วัดหลัก 5 การ์ด, กราฟแนวโน้มรายเดือน, อันดับจังหวัด, และแผนภูมิกระจายตัวข้อมูล |
| **2. ภูมิอากาศพื้นที่สูง** | **Q1, Q2** | แนวโน้มสภาพอากาศรายสถานี 6 ตัวชี้วัด, อันดับสถานี, แผนภูมิความร้อนเมทริกซ์ 50 สถานี × 12 เดือน (Missing ≠ 0) |

| **4. สำรวจจุดความร้อน** | **Q5** | แผนที่แสดงจุดความร้อนแบบ Lazy-loading และ Marker Clustering, การจำแนกตามประเภทป่า/การใช้ที่ดิน (Land Use), ระดับความสูง (>500 ม.), และพื้นที่โครงการ HRDI |
| **5. ความสัมพันธ์สภาพอากาศกับจุดความร้อน** | **Q6, Q7, Q8** | กราฟกระจายตัว (Scatter Plots) พร้อมเส้นถดถอยเชิงเส้น (Linear Regression), สหสัมพันธ์เพียร์สัน (*r*), รัศมี 10 กม. รอบสถานี, และการวิเคราะห์ช่วงเวลาหน่วง (Lagged Effect 1 เดือน) |

## วิธีการรันแดชบอร์ด (How to Run)

แดชบอร์ดเป็น Pure Client-Side Application (HTML5 / ES Modules / CSS3) สามารถเปิดผ่าน Local Web Server ใดๆ ได้ทันที:

### วิธีที่ 1: รันผ่าน Windows PowerShell Helper Script (เร็วที่สุด)
ดับเบิลคลิกไฟล์หรือรันคำสั่งใน PowerShell:
```powershell
.\run-server.ps1
```
จากนั้นเปิดบราวเซอร์ไปที่:
👉 **`http://localhost:8000`**

### วิธีที่ 2: รันผ่าน Python
```bash
python -m http.server 8000
```
เปิดบราวเซอร์ไปที่: `http://localhost:8000`

### วิธีที่ 3: รันผ่าน npx / Node.js
```bash
npx serve . -p 8000
```

### การ Deploy บน GitHub Pages
1. Push โค้ดขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Source: Branch `main`, โฟลเดอร์ `/(root)`
4. บันทึก (Save) ระบบจะเปิดให้ใช้งานทันทีเนื่องจากพาธของไฟล์ทั้งหมดใช้ Relative Paths

## กฎความถูกต้องทางวิทยาศาสตร์และข้อมูล (Analytical Guardrails)

1. **Zero Fake/Synthetic Data:** ใช้เฉพาะไฟล์ JSON จริงในโฟลเดอร์ `data/` ไม่มีการสร้างข้อมูลจำลอง
2. **No Forecasting / Prediction:** แสดงเฉพาะข้อมูลเชิงประวัติศาสตร์ ไม่มีการพล็อตกราฟทำนายอนาคต
3. **Fair Paired Year-over-Year:** เปรียบเทียบเฉพาะสถานีและเดือนที่มีข้อมูลบันทึกจริงตรงกันทั้ง 2 ปี (Jan–Sep, $N=391$) หากขาดข้อมูลจะแสดงผลเป็น `N/A` หรือ `—`
4. **No Station Rain Summation:** ไม่นำผลรวมฝนของสถานีต่างจุดมาบวกเป็นยอดรวมจังหวัด
5. **Rainfall Comparability Gate:** แยกการแสดงผลฝน HRDI และ HII อย่างชัดเจน พร้อมแจ้งเตือนข้อจำกัดเชิงมาตรวัด
6. **No Emoji Policy:** ใช้การจัดวางและสัญลักษณ์กราฟิกแบบมาตรฐานสากลเพื่อความน่าเชื่อถือระดับมืออาชีพ
