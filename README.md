# สภาพภูมิอากาศและจุดความร้อนบนพื้นที่สูง (ปี 2022–2023)
## Highland Climate & Hotspot Dashboard

เว็บแดชบอร์ดเชิงโต้ตอบแนว **Clean Cinematic Highland Dashboard** สำหรับสำรวจและวิเคราะห์ข้อมูลสภาพภูมิอากาศพื้นที่สูง (50 สถานีตรวจวัด), ปริมาณน้ำฝนระดับจังหวัด (HII) และจุดความร้อนจากดาวเทียม VIIRS (106,036 จุด) ในพื้นที่ศึกษา 9 จังหวัดของประเทศไทย ปี พ.ศ. 2565–2566 (ค.ศ. 2022–2023)

พัฒนาด้วย Vanilla HTML5, CSS3 และ Modern JavaScript ES Modules โดยใช้ข้อมูลจริงจากไฟล์ JSON ในโฟลเดอร์ [`data/`](file:///c:/Users/kanok/OneDrive/เอกสาร/project_DataViz_Highland/data) 100%

## จุดเด่นของการปรับปรุงล่าสุด (Clean Cinematic Highland Dashboard)

1. **เข้าใจได้ทันทีภายในไม่กี่วินาที (Human-First Clarity)**:
   - **Header สั้นกระชับ**: แสดงหัวข้อหลัก `สภาพภูมิอากาศและจุดความร้อนบนพื้นที่สูง` และข้อความรอง `สำรวจข้อมูล 9 จังหวัดในประเทศไทย ปี 2022–2023`
   - **แท็บนำทาง Q1–Q5 อ่านง่าย**: `Q1 — ภาพรวม`, `Q2 — แนวโน้ม`, `Q3 — จุดความร้อน`, `Q4 — ความสัมพันธ์`, `Q5 — ข้อมูลและที่มา`
   - **ชื่อกราฟแบบคำถามธรรมชาติ**: เช่น `จังหวัดไหนมีอุณหภูมิเฉลี่ยสูงที่สุด?`, `ฝนตกมากช่วงเดือนไหน?`, `จุดความร้อนกระจุกตัวอยู่ที่ไหน?`, `ฝนกับจุดความร้อนเกี่ยวข้องกันไหม?`
   - **การ์ด KPI สะอาดตา + ปุ่ม `(i)` Info Popover**: แสดงเฉพาะไอคอน ชื่อตัวชี้วัด ค่าหลัก หน่วย และการเปลี่ยนแปลงเทียบปี ส่วนรายละเอียดวิธีคำนวณ จำนวนตัวอย่าง `N` และชื่อไฟล์ข้อมูลอยู่ในปุ่ม `(i)`
   - **สรุป `สิ่งที่น่าสนใจ` (Dynamic Key Insights)**: คำนวณข้อค้นพบสำคัญ 1–2 ประโยคจากข้อมูลจริงตามตัวกรองที่เลือกในทุกแท็บ

2. **แผนที่ Choropleth ทำงานได้โดยไม่ต้องใช้ API Key (Zero External Tile Dependencies)**:
   - วาดขอบเขตจังหวัดจากไฟล์ [`data/thailand_provinces.geojson`](file:///c:/Users/kanok/OneDrive/เอกสาร/project_DataViz_Highland/data/thailand_provinces.geojson) ครบ 77 จังหวัดบนพื้นหลังสีฟ้าอ่อนสะอาดตา ไม่มีปัญหา `API KEY REQUIRED`
   - แทนที่เส้นลากแบ่งแผนที่ด้วยปุ่มโหมดปีบนแผนที่ **`ปี 2022 | ปี 2023 | เปรียบเทียบ`** โดยโหมด `เปรียบเทียบ` แสดงเฉดสีตามผลต่าง (`ปี 2023 − ปี 2022`) พร้อมแสดงค่าปี 2022, ค่าปี 2023, ผลต่าง และ `%` การเปลี่ยนแปลงเมื่อชี้หรือคลิกจังหวัด
   - มีปุ่ม **`แสดงสถานีตรวจวัด`** สำหรับเปิด/ปิดจุดสถานี 50 แห่งบนแผนที่เพื่อไม่ให้จุดทับสีจังหวัด

3. **ระบบตัวกรอง 2 ระดับ (Two-Level Filter System) + Cross-filtering เต็มรูปแบบ**:
   - **ตัวกรองหลัก 4 ตัว** ที่เห็นได้ทันที: `1. ปีที่ศึกษา`, `2. ช่วงเดือน`, `3. จังหวัด`, `4. ตัวชี้วัดหลัก`
   - **ปุ่ม `ตัวกรองเพิ่มเติม`** เปิด/พับเก็บตัวกรองละเอียด (`อำเภอ`, `ตำบล`, `สถานีตรวจวัด`, `แหล่งข้อมูลอากาศ`, `แหล่ง KPI ฝน`, `ระดับความสูงจุดความร้อน`, `ประเภทการใช้ประโยชน์ที่ดิน`, `พื้นที่โครงการ HRDI`) พร้อมป้ายนับจำนวนตัวกรองย่อยที่เปิดใช้งาน โดยเมื่อพับเก็บจะไม่ล้างค่าที่เลือกไว้

## วิธีการรันระบบในเครื่อง (Local Execution)

สามารถเปิดใช้งานผ่าน HTTP Server มาตรฐานได้ทันที:

```powershell
# วิธีที่ 1: ใช้สคริปต์ PowerShell ของโปรเจกต์
.\run-server.ps1

# วิธีที่ 2: ใช้ Python HTTP Server
python -m http.server 8000
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
