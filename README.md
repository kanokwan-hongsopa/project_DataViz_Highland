# Highland Climate & Hotspot Interactive Dashboard (2022–2023)

> **การวิเคราะห์แนวโน้มสภาพภูมิอากาศและความสัมพันธ์กับจุดความร้อนบนพื้นที่สูงของประเทศไทย ปี 2022–2023**

Interactive Web Dashboard สำหรับการสำรวจ วิเคราะห์ และเปรียบเทียบข้อมูลสภาพภูมิอากาศรายสถานีบนพื้นที่สูง (HRDI) ปริมาณน้ำฝนระดับจังหวัด (HII) และรายการตรวจพบจุดความร้อนจากดาวเทียม (Satellite Hotspots) ใน 9 จังหวัดภาคเหนือและภาคตะวันตกของประเทศไทย เพื่อตอบคำถามวิจัยและวิเคราะห์หลัก 9 ข้อ (Q1–Q9) ตามข้อกำหนดใน [BRD.md](BRD.md) และ [HANDOFF.md](HANDOFF.md)

---

## 📌 ภาพรวมโครงการ (Project Overview)

โครงการนี้พัฒนาเว็บแดชบอร์ดเชิงโต้ตอบ (Interactive Analytical Dashboard) ด้วยสถาปัตยกรรม Pure Front-end (Vanilla HTML5, CSS3, Modern JavaScript ES Modules) โดยทำงานกับชุดข้อมูลจริงขนาด 106,036 รายการจุดความร้อน, 50 สถานีตรวจวัดสภาพอากาศ, 977 ข้อมูลรายสถานี-เดือน และ 216 ข้อมูลฝนระดับจังหวัด-เดือน โดยไม่มีการสังเคราะห์หรือแต่งเติมข้อมูล (No mock/synthetic data)

### ขอบเขตการศึกษา
- **ช่วงเวลาศึกษา:** ปี ค.ศ. 2022 และ 2023 เท่านั้น (ย้อนหลังเชิงประวัติศาสตร์ ไม่ใช่ระบบติดตามสดหรือเตือนภัยล่วงหน้า)
- **พื้นที่ศึกษา 9 จังหวัด:** เชียงใหม่, เชียงราย, น่าน, ตาก, กำแพงเพชร, พิษณุโลก, เพชรบูรณ์, กาญจนบุรี, แม่ฮ่องสอน
- **สถานีตรวจวัดพื้นที่สูง HRDI:** 50 สถานี (977 station-month records)
- **ฝนระดับจังหวัด HII:** 9 จังหวัด × 24 เดือน (216 province-month records)
- **จุดความร้อนจากดาวเทียม:** 106,036 detection records (แบ่งเป็น 24 ไฟล์พาร์ทิชันรายเดือน)

## 🧭 การจัดหน้าและคำถามวิเคราะห์หลัก (Q1–Q9)

แดชบอร์ดแบ่งออกเป็น 5 หน้า/แท็บหลัก โดยแสดงตัวบ่งชี้ระบุคำถามวิจัย (Q1–Q9) อย่างชัดเจน:

| หน้า (Tab) | คำถามที่ครอบคลุม | สาระสำคัญในการวิเคราะห์ |
|---|---|---|
| **1. Overview** (ภาพรวม 9 จังหวัด) | **Q1, Q5, Q9** | ภาพรวมตัวชี้วัดหลัก (KPIs), แผนที่กระจายตัวสถานีและจุดความร้อน, แนวโน้มสภาพอากาศและจุดความร้อนรายเดือน, อันดับจังหวัด, และสรุปการเปลี่ยนแปลงรายปี (YoY) |
| **2. Highland Climate** (ภูมิอากาศพื้นที่สูง) | **Q1, Q2** | แนวโน้มสภาพภูมิอากาศรายสถานี (อุณหภูมิ, อุณหภูมิต่ำสุด/สูงสุด, ฝน, ความชื้น, ความเร็วลม), อันดับสถานี, แผนภูมิความร้อน (Heatmap สถานี × เดือน), และการเปรียบเทียบข้ามสถานี |
| **3. Rainfall Comparison** (เปรียบเทียบฝน) | **Q3, Q4** | เปรียบเทียบปริมาณฝนสถานีพื้นที่สูง (HRDI) กับฝนระดับจังหวัด (HII), ความสัมพันธ์รายเดือน, และข้อจำกัดความหมายเชิงปริมาณ (Comparability Gate) |
| **4. Hotspot Explorer** (สำรวจจุดความร้อน) | **Q5** | แผนที่จุดความร้อนแบบละเอียดพร้อมการโหลดแบบแบ่งส่วน (Partitioned Loading), การจัดกลุ่มจุด (Clustering), การเจาะลึกเชิงพื้นที่ (จังหวัด → อำเภอ → ตำบล), การจำแนกตามประเภทป่า/การใช้ที่ดิน (Land Use), ระดับความสูง (>500 ม.), และพื้นที่โครงการ HRDI |
| **5. Climate × Hotspot** (ความสัมพันธ์อากาศ-จุดความร้อน) | **Q6, Q7, Q8** | กราฟการกระจายตัว (Scatter Plots) ความสัมพันธ์ระหว่างปริมาณฝน/อุณหภูมิ/ความชื้นกับจุดความร้อนรอบสถานี (รัศมี 10 กม. หรือตำบลเดียวกัน), ค่าสัมประสิทธิ์สหสัมพันธ์ (Pearson *r* พร้อมระบุขนาดตัวอย่าง *N*), และการวิเคราะห์ช่วงเวลาหน่วง (Lagged Exploratory Analysis) |

## 📊 แหล่งข้อมูลต้นทาง (Data Sources & Provenance)

ชุดข้อมูลทั้งหมดจัดเก็บในโฟลเดอร์ `data/` โดยรักษาโครงสร้างและไฟล์ต้นฉบับเดิมไว้ทั้งหมด:

1. **`data/dashboard_config.json`**: คอนฟิกพื้นฐาน ขอบเขตปี จังหวัด และข้อกำหนดการวิเคราะห์
2. **`data/stations.json`**: ข้อมูลสถานีตรวจวัด 50 สถานี (ชื่อสถานี, ละติจูด, ลองจิจูด, จังหวัด, อำเภอ, ตำบล, ประเภทเซนเซอร์)
3. **`data/hrdi_station_month.json`**: ข้อมูลตรวจวัดสภาพอากาศรายเดือนของสถานี HRDI (977 แถว)
4. **`data/hii_province_month.json`**: ข้อมูลปริมาณน้ำฝนระดับจังหวัดรายเดือนจาก HII (216 แถว)
5. **`data/station_month_dashboard.json`**: ข้อมูลรวมระดับสถานี-เดือน เชื่อมโยงฝน HII และจำนวนจุดความร้อนรอบสถานี (977 แถว)
6. **`data/hotspot_manifest.json`** และ **`data/hotspots/YYYY/MM.json`**: ดัชนีพาร์ทิชันและไฟล์จุดความร้อนรายเดือน 24 พาร์ทิชัน (รวม 106,036 แถว)
7. **`data/hotspot_province_month.json`**, **`hotspot_district_month.json`**, **`hotspot_by_elevation.json`**, **`hotspot_by_landuse.json`**, **`hotspot_by_project.json`**: ข้อมูลรวมมิติเชิงพื้นที่และประเภทสำหรับการแสดงผลสรุปอย่างรวดเร็ว

## ⚙️ กฎการคำนวณและข้อตกลงทางสถิติ (Analytical Contracts)

- **นิยามจุดความร้อน:** คือ "รายการตรวจพบจุดความร้อนจากดาวเทียม" (Satellite Hotspot Detections) ไม่ใช่ "จำนวนครั้งที่เกิดไฟป่าที่ยืนยันแล้ว"
- **การเปรียบเทียบรายปี (Fair YoY Comparison):**
  - เปรียบเทียบเฉพาะสถานีและเดือนที่มีข้อมูลบันทึกจริงตรงกันทั้งสองปี (Paired Station-Month Keys: `station_id + month`)
  - ช่วงเวลามาตรฐานเปรียบเทียบคือเดือน **มกราคม – กันยายน (Jan–Sep)** เนื่องจากข้อมูล HRDI ปี 2023 สิ้นสุดในเดือนกันยายน
  - หากไม่มีคู่ข้อมูลที่ตรงกัน ให้แสดงผล `N/A` (ไม่มีข้อมูลเปรียบเทียบ) และไม่นำข้อมูลปีที่มีไปเทียบกับศูนย์
- **การรวมข้อมูลฝนสถานี:** ใช้ค่าเฉลี่ยฝนต่อสถานีที่รายงานจริง (Mean Monthly Rainfall across reporting stations) โดยไม่นำยอดรวมฝนของหลายสถานีมาบวกกันเป็นยอดฝนของจังหวัด
- **การเปรียบเทียบฝน HRDI กับ HII:** มีสวิตช์ควบคุม `rainfallComparable` (ค่าเริ่มต้น: `false`) เพื่อป้องกันการหักลบผลต่างเชิงตัวเลขหรือการจัดอันดับผลต่างที่อาจสร้างความเข้าใจผิด เนื่องจากหน่วยและวิธีการคำนวณของทั้งสองแหล่งข้อมูลมีความแตกต่างกัน โดยนำเสนอเป็นกราฟคู่เพื่อดูทิศทางแนวโน้มร่วมกัน
- **ความสัมพันธ์แบบหน่วงเวลา (Lagged Analysis):** จับคู่เฉพาะเดือนที่ต่อเนื่องกันตามปฏิทินจริงของสถานีเดียวกันที่มีข้อมูลสมบูรณ์เท่านั้น
- **ข้อห้ามเด็ดขาด (Strict Guardrails):**
  - **ไม่มีการพยากรณ์ คาดการณ์ หรือเส้นประจำลองอนาคต (No Forecasting / No Future Predictions)**
  - **ไม่มีการแทนค่าสูญหายด้วยศูนย์ (Missing ≠ 0)**
  - **ไม่มีการแสดงหน้า Data Cleaning หรือ Audit ภายใน**

## 🚀 วิธีการติดตั้งและเปิดใช้งาน (Setup & How to Run)

แดชบอร์ดนี้เป็นเว็บแอปพลิเคชันแบบ Client-side Static Web จึงไม่จำเป็นต้องติดตั้งฐานข้อมูลหรือสร้างระบบ Backend พิเศษ

### ข้อกำหนดเบื้องต้น
- เว็บบราวเซอร์รุ่นใหม่ที่รองรับ ES6 Modules (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari)
- โปรแกรม Web Server ขนาดเล็กในเครื่อง เช่น Python, Node.js, หรือ Visual Studio Code Live Server (เนื่องจากเบราว์เซอร์จะไม่อนุญาตให้ `fetch()` อ่านไฟล์ JSON ผ่านโปรโตคอล `file://` ด้วยเหตุผลด้านความปลอดภัย CORS)

### วิธีการรันผ่าน Python (แนะนำ)
เปิด Terminal หรือ PowerShell ในโฟลเดอร์โครงการ แล้วสั่งรัน:
```bash
# สำหรับ Python 3
python -m http.server 8000
```
จากนั้นเปิดเว็บบราวเซอร์ไปที่:
👉 **`http://localhost:8000`**

### วิธีการรันผ่าน Node.js / npx
```bash
npx serve .
# หรือ
npx http-server -p 8000
```

### การ Deploy บน GitHub Pages
1. นำโค้ดขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Source เป็น Branch `main` และโฟลเดอร์ `/(root)`
4. บันทึก (Save) ระบบจะ Deploy ให้พร้อมใช้งานทันที เนื่องจากโครงสร้างไฟล์ใช้ Relative Paths ทั้งหมด

## 🎨 การออกแบบและการใช้งาน (Visual Design & Accessibility)

- **จานสี (Color Palette):** ได้รับแรงบันดาลใจจากธรรมชาติ ป่าเขา และสายหมอก (Deep Navy `#1a365d`, Alpine Slate `#2b6cb0`, Teal `#0d9488`, Forest Emerald `#10b981`, Mist White `#f8fafc`)
- **การจัดวาง (Layout):** Top Navigation Bar, Clean Global Filter Panel พร้อม Breadcrumbs และปุ่ม Reset, Bento Grid Dashboard Cards
- **การตอบสนอง (Cross-filtering):** การคลิกบนหมุดสถานี, แท่งกราฟจังหวัด, หรือตัวเลือกบนแถบกรอง จะอัปเดตทุกหน้าต่างที่เกี่ยวข้องทันที และสถานะการเลือกจะคงอยู่เมื่อสลับแท็บ
- **การรองรับหน้าจอ:** รองรับทั้งจอคอมพิวเตอร์ Desktop และอุปกรณ์หน้าจอสัมผัส/Mobile Responsive

## ⚖️ ข้อจำกัดทางสถิติและการอ้างอิง (Data Caveats)

1. ข้อมูลสภาพอากาศ HRDI รวบรวมจากเซนเซอร์เฉพาะจุดบนพื้นที่สูง ไม่สามารถใช้แทนค่าเฉลี่ยของทั้งอำเภอหรือจังหวัดได้
2. ข้อมูลจุดความร้อนจากดาวเทียม VIIRS แสดงถึงพิกัดและช่วงเวลาที่ตรวจพบอุณหภูมิพื้นผิวสูงผิดปกติ ซึ่งอาจเกิดจากไฟป่า การเผาทางการเกษตร โรงงานอุตสาหกรรม หรือหินร้อนสะท้อนแสง
3. ค่าสัมประสิทธิ์สหสัมพันธ์ (Correlation) เป็นการสำรวจความสัมพันธ์เชิงสถิติเบื้องต้น ไม่สามารถสรุปความสัมพันธ์เชิงสาเหตุ (Causation) หรือใช้พยากรณ์เหตุการณ์ในอนาคตได้
